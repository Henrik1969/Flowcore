# Flowmini v0.24 C5 Typed Statement Payload Sitrep

## Result

C5a-C5f are complete in the v0.24 explicit-AST implementation.

`Statement` now contains only its source location and one typed payload variant.
Statement kind is derived from that payload. The earlier shared collection of
names, types, presence flags, expression lists, body IDs, and else data has
been removed.

This closes the C5 statement-representation migration. It does not close the
v0.24 raw-frontend gate; the accepted-language coverage matrix still records
missing ABI, refined-contract, projection, and provenance work.

## Canonical representation

```text
Statement
    location
    payload = variant<
        LetStatement,
        AssignmentStatement,
        PlacementStatement,
        IfStatement,
        WhileStatement,
        BreakStatement,
        ContinueStatement,
        ReturnStatement,
        ExpressionStatement,
        FlowStatement,
        UnknownStatement
    >
```

The payload is the discriminator. There is no independently stored
`StatementKind` that can disagree with it.

Current payload ownership is:

```text
LetStatement
    name
    type
    optional initializer ExpressionId

AssignmentStatement
    AssignableTarget
    optional value ExpressionId
    EqualsAssignment source form

PlacementStatement
    value ExpressionId
    AssignableTarget
    ArrowPlacement source form

IfStatement
    condition ExpressionId
    then BlockId
    optional ElseArm

WhileStatement
    condition ExpressionId
    body BlockId

ReturnStatement
    optional value ExpressionId
    KeywordReturn or ArrowPlacement source form
```

Break and Continue are explicit zero-field payload alternatives. Expression,
Flow, and Unknown also have dedicated payloads rather than borrowing fields
from unrelated statement forms.

## Structural ownership

If owns its condition, mandatory then block, and optional tagged ElseArm.

```text
ElseArm = ElseBlock(BlockId) | ElseIf(StatementId)
```

Else-if remains a direct structural continuation. While owns its condition and
body block. Blocks own ordered StatementIds; the statement and block arenas
continue to own node storage. SymbolTable projection follows these IDs but does
not duplicate AST ownership.

## Placement and return

The raw AST now distinguishes storage placement from control transfer:

```text
value -> target
    PlacementStatement(value, target, ArrowPlacement)

value -> return
    ReturnStatement(value, ArrowPlacement)

return value
    ReturnStatement(value, KeywordReturn)
```

Return is never represented as an assignable target.

The v0.24 target family is closed:

```text
IdentifierTarget(name, location)
FieldPathTarget(base, base location, ordered located field segments)
IndexedTarget(base, base location, one-or-more index ExpressionIds)
```

The focused placement probe covers an identifier, a multi-segment field path,
a single index, multiple indexes, and arrow-return. The same probe is accepted
by the executable parser, confirming that these forms belong to the currently
accepted language.

## Compatibility projections

The AST JSON keeps existing consumer-facing fields such as `kind`, `name`,
`type`, `has_value`, `has_condition`, block fields, and `expression_ids`.
They are generated from canonical payloads and are not stored as competing
statement state.

The golden validator requires exact statement-payload field sets and verifies
that every compatibility projection agrees with its payload. It also validates
assignable-target shape, source form, expression references, arena IDs, unique
structural parents, and ElseArm targets.

## Remaining risks and next work

The raw AST builder and executable parser still contain separate recognition
code. The placement probe demonstrates agreement for the covered accepted
forms, but future grammar changes must update both paths or consolidate their
syntax authority.

The explicit AST builder also remains deliberately incomplete for other
accepted constructs. The active completion checklist is:

```text
docs/flowmini/v0.24-accepted-language-coverage.md
```

The next work must close that matrix rather than begin semantic analysis.
Graph IR remains later than AST, SymbolTable projection, and semantic facts.
