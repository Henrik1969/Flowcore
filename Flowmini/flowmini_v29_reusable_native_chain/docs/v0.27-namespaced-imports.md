# Flowmini namespaced imports

Flowmini imports may declare a source namespace alias:

```flow
import "../../../std/abi/ncurses.flow" as curses
import "../../../std/abi/libc.flow" as libc

curses.initscr() -> window
libc.puts(message) -> status
```

The alias is part of the AST import declaration and is retained in frontend
artifacts. During expansion, the imported ABI contract is projected under the
alias, and qualified calls resolve to the member symbol owned by that
contract. Provider library, external symbol, calling convention, effects and
signature facts remain unchanged.

Legacy unaliased imports remain accepted for compatibility. Their ABI block
name is the namespace, and an unqualified member is available only while its
short name is unambiguous. Qualified calls are the canonical form when two
providers expose the same spelling, for example `libc.read()` versus
`linux.read()`.

The semantic report records the qualified source callee while binding
requirements continue to carry the provider's external symbol. This keeps
source ownership visible without changing the native ABI name.
