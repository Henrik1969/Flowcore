## Stripping recovery

The book's online stripping sequence attempted to replace libraries loaded by
the running `strip`/`install` process. Demand paging caused `libzstd` and then
`libsframe` to be truncated. This was detected before sealing.

`libzstd` was temporarily bootstrapped with the builder host's compatible
SONAME solely to permit a complete rebuild from the pinned Zstd archive. The
temporary file was then replaced by that canonical target build. `libsframe`
was recovered from the immutable `ch7-ready` checkpoint, which contains the
same pinned Binutils-produced library. Final sizes and target dynamic linking
were validated. No host recovery library remains in the checkpoint.

The finalizer now exempts its live dependency set from in-process replacement
and fails on any other ELF stripping error. The corrected pass completed, and
all recovery artifacts outside permanent evidence were removed.
