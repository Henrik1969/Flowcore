Kort version:

    #!/bin/bash = kør lige præcis det bash-binær der ligger i /bin/bash.

    #!/usr/bin/env bash = brug env til at slå bash op via $PATH og kør dét.

env er bare et lille program, der finder programmet i din PATH og exec’er det. Så:

#!/usr/bin/env bash

betyder reelt:

    Find bash sådan som brugeren normalt ville finde det (via PATH), og brug dét.

Hvorfor gider folk det?

Fordi verden er rodet:

    På “klassisk” Linux: bash ligger typisk i /bin/bash → #!/bin/bash virker fint.

    På nogle systemer (BSD’er, Nix, macOS med Homebrew, custom setups): bash kan ligge i /usr/local/bin/bash eller et andet sted.

    Men env ligger næsten altid i /usr/bin/env, og det bruger $PATH til at finde bash.

Hvis du skriver scripts, der skal kunne køre mange steder (fx delt via git, eller på andres maskiner), så er:

#!/usr/bin/env bash

mere portabel end:

#!/bin/bash

Det samme mønster bruges for Python, Perl osv.:

#!/usr/bin/env python3
#!/usr/bin/env perl

Hvornår er /bin/bash bedre?

Når du vil være helt sikker på præcis hvilken interpreter du kører, f.eks.:

    System-scripts, der er afhængige af at det er distroens egen bash.

    Når du ved, at miljøet (PATH) kan være amputeret (fx under sudo/cron/chroot), men /bin/bash er garanteret der.

Her er det ofte mere robust at hardcode path:

#!/bin/bash

Ulemper ved /usr/bin/env bash

    Hvis $PATH er fucked (tom, eller uden bash), så finder den ikke bash.

    Hvis brugeren har en “mærkelig” bash først i PATH (fx en gammel lokal build), så får du den i stedet for systemets.

    Det er en ekstra exec (mikroskopisk overhead, men teknisk set der).

På en maskine som din, hvor du har fuld kontrol, kan du roligt sige:

    Scripts kun til dine maskiner?
    → #!/bin/bash er helt fint og simpelt.

    Scripts i repos, der skal køre alle mulige steder?
    → #!/usr/bin/env bash er ofte det klogeste valg.

Så ja: env i shebang’en er bare et portabilitets-hack, ikke noget magisk. Det svarer til at sige: “Brug den bash, som denne bruger normalt ville få, ikke nødvendigvis den systemet tror er standard.”

1. PEGTL – tag den som “vendored” (det er header-only)

PEGTL er header-only C++-code, så den behøver egentlig ingen systempakke.
Det mest robuste er faktisk at tage den ind i projektet selv.
A) Globalt (fælles libs-dir)

mkdir -p ~/src/libs
cd ~/src/libs
git clone https://github.com/taocpp/PEGTL.git pegtl

Så har du den liggende ét sted.
B) Brug den fra CMake med FetchContent (min anbefaling)

I dit CMake-projekt:

include(FetchContent)

FetchContent_Declare(
  pegtl
  GIT_REPOSITORY https://github.com/taocpp/PEGTL.git
  GIT_TAG        3.2.7   # eller en anden tag du vil låse til
)

FetchContent_MakeAvailable(pegtl)

add_executable(my_lang main.cpp parser.cpp)
target_link_libraries(my_lang PRIVATE taocpp::pegtl)
target_compile_features(my_lang PRIVATE cxx_std_17)

Så er du helt uafhængig af distroens pakkepolitik.
2. linenoise – tag linenoise-ng som kilde

mkdir -p ~/src/libs
cd ~/src/libs

Du kan så enten:

    installere den systembredt (klassisk cmake && make && sudo make install), eller

    lade CMake i dit projekt pege direkte på kildekoden.

#!/usr/bin/env bash
#
# dev_pkg_overview.sh
# Simpelt overblik over dev-relaterede pakker og deres versioner.
#

set -u

RED=$'\e[31m'
GREEN=$'\e[32m'
YELLOW=$'\e[33m'
BLUE=$'\e[34m'
RESET=$'\e[0m'

print_header() {
    printf "\n%s== %s ==%s\n" "$BLUE" "$1" "$RESET"
}

print_pkg() {
    local pkg="$1"
    if dpkg-query -W -f='${Status}' "$pkg" 2>/dev/null | grep -q "install ok installed"; then
        local ver
        ver=$(dpkg-query -W -f='${Version}' "$pkg" 2>/dev/null)
        printf "  %b[OK ]%b %-20s %s\n" "$GREEN" "$RESET" "$pkg" "$ver"
    else
        printf "  %b[MISS]%b %-20s %s\n" "$RED" "$RESET" "$pkg" "IKKE installeret"
    fi
}

# -- Kategorier ------------------------------------------

  qtcreator
)

)

  graphviz
)

echo
echo "=== Dev-pakkeoverblik på $(hostname) ==="
echo "Kernel: $(uname -r)"
echo

done

print_header "Debuggere"
for p in "${debug_tools[@]}"; do
  print_pkg "$p"
done

print_header "Statisk analyse"
for p in "${analysis_tools[@]}"; do
  print_pkg "$p"
done

print_header "Tracing / systemanalyse"
for p in "${sys_trace[@]}"; do
  print_pkg "$p"

print_header "Sprog/lexer/parser-værktøj"

  print_pkg "$p"

        [OP_NOP]        = &&do_nop,
        [OP_ADD]        = &&do_add,

        [OP_XOR]        = &&do_xor,
        [OP_NOT]        = &&do_not,
        [OP_SHL]        = &&do_shl,
        [OP_SHR]        = &&do_shr,
        [OP_CMP]        = &&do_cmp,
        [OP_JMP]        = &&do_jmp,
        [OP_JZ]         = &&do_jz,
        [OP_JNZ]        = &&do_jnz,
        [OP_LOAD]       = &&do_load,
        [OP_STORE]      = &&do_store,
        [OP_MOV]        = &&do_mov,
        [OP_PUSH]       = &&do_push,
        [OP_POP]        = &&do_pop,
        [OP_CTX_PUSH]   = &&do_ctx_push,
        [OP_CTX_COMMIT] = &&do_ctx_commit,
        [OP_CTX_ABORT]  = &&do_ctx_abort,
        [OP_CTX_HASCHK] = &&do_ctx_haschk,
        [OP_CTX_COPY]   = &&do_ctx_copy,
        [OP_HALT]       = &&do_halt
    };

    ctx->running = true;

    while (ctx->running && ctx->pc < ctx->program_len) {
        InstrWord *i = &prog[ctx->pc++];

do_shl:         op_shl (ctx, &prog[ctx->pc - 1]); continue;

int64_t vm_read_mem(vm_context *ctx, size_t addr) {
    if (!ctx->mem || addr + sizeof(int64_t) > ctx->mem_size) {
        fprintf(stderr, "[VM] read out of range: %zu\n", addr);
        return 0;
    }
    int64_t v = 0;
    memcpy(&v, ctx->mem + addr, sizeof(int64_t));
    return v;
}

void vm_write_mem(vm_context *ctx, size_t addr, int64_t value) {
    if (!ctx->mem || addr + sizeof(int64_t) > ctx->mem_size) {
        fprintf(stderr, "[VM] write out of range: %zu\n", addr);
        return;
    }
    memcpy(ctx->mem + addr, &value, sizeof(int64_t));
}

void op_sub(vm_context *c, InstrWord *i) { vm_trace(c, "SUB", i); R(i->a) -= R(i->b); }
void op_mul(vm_context *c, InstrWord *i) { vm_trace(c, "MUL", i); R(i->a) *= R(i->b); }
void op_div(vm_context *c, InstrWord *i) { vm_trace(c, "DIV", i); if (R(i->b)) R(i->a) /= R(i->b); }
void op_mod(vm_context *c, InstrWord *i) { vm_trace(c, "MOD", i); if (R(i->b)) R(i->a) %= R(i->b); }
void op_and(vm_context *c, InstrWord *i) { vm_trace(c, "AND", i); R(i->a) &= R(i->b); }
void op_or (vm_context *c, InstrWord *i) { vm_trace(c, "OR",  i); R(i->a) |= R(i->b); }
void op_xor(vm_context *c, InstrWord *i) { vm_trace(c, "XOR", i); R(i->a) ^= R(i->b); }
void op_not(vm_context *c, InstrWord *i) { vm_trace(c, "NOT", i); R(i->a) = ~R(i->a); }
void op_shl(vm_context *c, InstrWord *i) { vm_trace(c, "SHL", i); R(i->a) <<= R(i->b); }
void op_shr(vm_context *c, InstrWord *i) { vm_trace(c, "SHR", i); R(i->a) >>= R(i->b); }

void op_cmp(vm_context *c, InstrWord *i) {
    vm_trace(c, "CMP", i);
    int64_t lhs = R(i->a);
    int64_t rhs = R(i->b);
    c->flags = 0;
    if (lhs == rhs) c->flags |= FLAG_Z;
    if (lhs <  rhs) c->flags |= FLAG_N;
}

void op_jmp(vm_context *c, InstrWord *i) {
    vm_trace(c, "JMP", i);
    c->pc = (c->pc - 1) + i->a;
}

void op_jz(vm_context *c, InstrWord *i) {
    vm_trace(c, "JZ", i);
    if (c->flags & FLAG_Z) c->pc = (c->pc - 1) + i->a;
}

void op_jnz(vm_context *c, InstrWord *i) {
    vm_trace(c, "JNZ", i);
    if (!(c->flags & FLAG_Z)) c->pc = (c->pc - 1) + i->a;
}

void op_load(vm_context *c, InstrWord *i) {
    vm_trace(c, "LOAD", i);
    R(i->a) = vm_read_mem(c, (size_t)R(i->b));

#include <tinyvm/tvm_loader.h>
#include <stdio.h>
#include <stdlib.h>

int tvm_load_file(const char *path, InstrWord **out_prog, size_t *out_len) {
    FILE *f = fopen(path, "rb");
    if (!f) return -1;

    if (fseek(f, 0, SEEK_END) != 0) {
        fclose(f);
        return -1;
    }
    long sz = ftell(f);
    if (sz < 0 || (size_t)sz % sizeof(InstrWord) != 0) {
        fclose(f);
        return -1;
    }
    rewind(f);

    size_t count = (size_t)sz / sizeof(InstrWord);
    InstrWord *buf = calloc(count, sizeof(InstrWord));
    if (!buf) {
        fclose(f);
        return -1;
    }

    if (fread(buf, sizeof(InstrWord), count, f) != count) {
        free(buf);
        fclose(f);
        return -1;
    }

    fclose(f);
    *out_prog = buf;
    *out_len  = count;
    return 0;
}

void tvm_free_program(InstrWord *prog) {
    free(prog);
}

#include <tinyvm/tinyvm.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <ctype.h>

#define MAX_LINES 4096

static void trim(char *s) {
    char *p = s;
    while (isspace((unsigned char)*p)) p++;
    if (p != s) memmove(s, p, strlen(p) + 1);

    size_t len = strlen(s);
    while (len && isspace((unsigned char)s[len - 1])) {
        s[--len] = '\0';
    }
}

static int parse_register(const char *s) {
    if (s[0] != 'r' && s[0] != 'R') return -1;
    int idx = atoi(s + 1);
    return idx;
}

static long long parse_immediate(const char *s) {
    if (s[0] == '#') s++;
    return strtoll(s, NULL, 0);
}

/* naive tabel baseret på mnemonics */
static int lookup_opcode(const char *mn) {
    struct { const char *name; int op; } tbl[] = {
        {"NOP", OP_NOP},
        {"ADD", OP_ADD},
        {"SUB", OP_SUB},
        {"MUL", OP_MUL},
        {"DIV", OP_DIV},
        {"MOD", OP_MOD},
        {"AND", OP_AND},
        {"OR",  OP_OR},
        {"XOR", OP_XOR},
        {"NOT", OP_NOT},
        {"SHL", OP_SHL},
        {"SHR", OP_SHR},
        {"CMP", OP_CMP},
        {"JMP", OP_JMP},
        {"JZ",  OP_JZ},
        {"JNZ", OP_JNZ},
        {"LOAD",  OP_LOAD},
        {"STORE", OP_STORE},
        {"MOV",   OP_MOV},
        {"PUSH",  OP_PUSH},
        {"POP",   OP_POP},
        {"CTX_PUSH",   OP_CTX_PUSH},
        {"CTX_COMMIT", OP_CTX_COMMIT},
        {"CTX_ABORT",  OP_CTX_ABORT},
        {"CTX_HASCHK", OP_CTX_HASCHK},
        {"CTX_COPY",   OP_CTX_COPY},
        {"HALT", OP_HALT}
    };
    for (size_t i = 0; i < sizeof(tbl)/sizeof(tbl[0]); ++i) {
        if (strcasecmp(mn, tbl[i].name) == 0) return tbl[i].op;
    }
    return -1;
}

int main(int argc, char **argv) {
    FILE *in  = stdin;
    FILE *out = stdout;

    if (argc >= 2 && strcmp(argv[1], "-") != 0) {
        in = fopen(argv[1], "r");
        if (!in) {
            perror("fopen input");
            return 1;
        }
    }
    if (argc >= 3 && strcmp(argv[2], "-") != 0) {
        out = fopen(argv[2], "wb");
        if (!out) {
            perror("fopen output");
            return 1;
        }
    }

    char line[256];
    InstrWord instrs[MAX_LINES];
    size_t count = 0;

    while (fgets(line, sizeof(line), in) && count < MAX_LINES) {
        trim(line);
        if (line[0] == '\0' || line[0] == ';') continue;

        char *tok = strtok(line, " ,\t");
        if (!tok) continue;

        int op = lookup_opcode(tok);
        if (op < 0) {
            fprintf(stderr, "Unknown opcode: %s\n", tok);
            return 1;
        }

        InstrWord inst = { .opcode = op, .a = 0, .b = 0, .pad = 0 };

        char *arg1 = strtok(NULL, " ,\t");
        char *arg2 = strtok(NULL, " ,\t");

        /* meget simpel konvention:
         *  rX,rY -> a = X, b = Y
         *  rX,#imm -> a = X, b = imm
         *  #off      -> a = off (til JMP/JZ/JNZ etc.)
         */
        if (arg1) {
            if (arg1[0] == 'r' || arg1[0] == 'R') {
                inst.a = parse_register(arg1);
            } else if (arg1[0] == '#') {
                inst.a = parse_immediate(arg1);
            }
        }
        if (arg2) {
            if (arg2[0] == 'r' || arg2[0] == 'R') {
                inst.b = parse_register(arg2);
            } else if (arg2[0] == '#') {
                inst.b = parse_immediate(arg2);
            }
        }

        instrs[count++] = inst;
    }

    if (fwrite(instrs, sizeof(InstrWord), count, out) != count) {
        perror("fwrite");
        return 1;
    }

    if (in  != stdin)  fclose(in);
    if (out != stdout) fclose(out);

    return 0;
}

5. TinyVM’s place in this universe

TinyVM then is:

    the default backend in your lab

    the small, fully controlled execution environment

    perfect for:

        testing IR

        doing runtime experiments

        embedding instrumentation (trace, perf probes, weird scheduling)

But because you’ve separated:

    “frontends + lab formats”

    from

    “backends (tinyvm / JIT / LLVM)”

you’re never locked in.

Short version:
You’re not just building FlowCore. You’re quietly sketching a general language experimentation framework where everything is a stream or a tree you can inspect, store, transform, and feed to different tools.
