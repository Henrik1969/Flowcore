# Flowkernel v0.1 boundary

The initial kernel matrix is intentionally narrow:

```text
read-only kernel access
private temporary filesystem transaction
child-process IPC
local Unix-socket IPC
```

The probes run direct Linux system calls and return a versioned
`flowkernel.probe_report`. They are safe to run on the development host under
ordinary user privileges. Later boundaries require stronger isolation:

```text
IPC/network namespaces → disposable VM
device/ioctl access    → explicitly selected device sandbox
mounts/cgroups/eBPF    → disposable VM with capability policy
```

No probe in v0.1 changes global kernel state, contacts an external network, or
touches host devices.
