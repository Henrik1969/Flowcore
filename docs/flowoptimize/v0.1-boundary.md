# Flowoptimize v0.1 boundary

Flowoptimize is an independent consumer of Flowanalyst output:

```text
flowanalyst.semantic_report v1
  → flowoptimize.optimization_report v1
```

The current implementation is intentionally a boundary proof. It accepts only
an `ok` Flowanalyst report and emits `ready` with no semantic transforms. When
the report carries Flowanalyst's `region_dependency` view, it preserves that
derived graph-to-matrix projection and exposes CPU/CUDA as runtime provider
candidates with CPU fallback. A rejected semantic report produces `blocked`
and exit status 2.

Future optimization must consume an accepted semantic bundle, preserve input
provenance, record transformation provenance, and emit a distinct versioned
state. It must never mutate or silently replace the semantic input.
