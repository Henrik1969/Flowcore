# Flowlower v0.1 LLVM boundary

Flowlower consumes an accepted optimization-stage report and selects the LLVM
backend provider:

```text
flowoptimize.optimization_report v1
  → flowlower.lowering_report v1
  → LLVM IR provider
```

The boundary currently supports two narrow source-derived profiles:

- `empty_program_main`, which emits a zero-returning `main`;
- `abi_abs_main`, which consumes an authorized Flowbind report and emits a
  libc `abs(i32)` call.

Both emit valid LLVM IR and the installed LLVM toolchain can produce an
executable. Other accepted programs still report `ir.status: not-emitted`;
general source lowering remains the next expansion.
