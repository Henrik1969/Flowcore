# Flowlower v0.1 LLVM boundary

Flowlower consumes an accepted optimization-stage report and selects the LLVM
backend provider:

```text
flowoptimize.optimization_report v1
  → flowlower.lowering_report v1
  → LLVM IR provider
```

The boundary currently supports the narrow `empty_program_main` trial profile.
For that profile it emits valid LLVM IR and the installed LLVM toolchain can
produce an executable. Other accepted programs still report
`ir.status: not-emitted`; general source lowering remains the next expansion.
