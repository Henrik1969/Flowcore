# Flowlower v0.1 LLVM boundary

Flowlower consumes an accepted optimization-stage report and selects the LLVM
backend provider:

```text
flowoptimize.optimization_report v1
  → flowlower.lowering_report v1
  → LLVM IR provider
```

The boundary consumes `flowcore.lowering_plan` version 1. Its typed structured
path emits scalar and pointer values, exact authorized external calls,
`argc`/`argv` access, nested branches and loops, assignments, conversions,
cleanup, and early returns. `sel` and `flowcat` use this path without
application/source-name or capability-set selection. Narrow compatibility
emitters remain for plan shapes not yet migrated.

Emitted LLVM IR is linked and executed throughout the native gates. Unsupported
operations fail explicitly rather than selecting behavior from a fixture name.
