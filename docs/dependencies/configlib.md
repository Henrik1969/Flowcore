# configlib dependency

Status: documented future dependency  
Version: configlib v1.0.0  
Integration status: not hard-wired into Flowmini v23 yet

configlib is a governed configuration library. It models configuration as facts, policies, schemas, resolving, diagnostics, runtime stores, scoped views, typed C++ bindings, and a C ABI.

Flowcore/Flowmini may use configlib later for session, tool, compiler, runtime, diagnostic, and backend policy.

For Flowmini v23, configlib is documented but not yet required by the build.
