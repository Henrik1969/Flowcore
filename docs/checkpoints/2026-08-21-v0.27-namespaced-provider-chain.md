# Flowcore v0.27 namespaced provider language-chain status

The active Flowcore prototype is now the v0.27 namespaced provider slice.

It preserves the verified v0.26 chain from Flowmini frontend export through
Flowanalyst, Flowparallel, Flowoptimize, Flowbind, Flowlower, LLVM, and native
ELF execution. The new boundary makes imported provider ownership explicit:

```flow
import "../../../std/abi/ncurses.flow" as curses
import "../../../std/abi/libc.flow" as libc

curses.initscr() -> window
libc.puts(message) -> status
```

Aliases are retained in frontend artifacts. Qualified calls resolve to the
provider contract's actual member symbols while binding requirements retain
the external ABI symbol, library, convention, effect, and signature facts.
Unqualified collisions are rejected with an ambiguity diagnostic.

The ncurses-backed `sel` application is the proof slice. It passes the full
chain and produces a runnable native ELF artifact. The complete CTest suite
passes 48/48 tests. The first v0.27 substrate iteration also adds the
`linux.getuid()`, `linux.getgid()`, `linux.geteuid()`, `linux.getegid()`, `linux.getppid()`, `linux.getpgrp()`, `linux.getpgid()`, `linux.getsid()`, and `linux.getpriority()` bindings: provider discovery, policy
authorization, profile propagation, LLVM lowering, and runtime identity
behavior are all covered.
