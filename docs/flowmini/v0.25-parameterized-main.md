# Parameterized `main`

FlowMini accepts the canonical application entry point:

```flow
main(args : list<string>) {
}
```

The parameter is represented in the AST as an ordinary typed parameter and
projected into the `main` function scope in the SymbolTable. Its source
location and declared type spelling remain available to downstream analysers.

This establishes the language boundary for process arguments. It does not yet
promise a runtime argv provider, list operations, or output lowering; those
belong to the standard-library and lowering stages. The first application
specimen is [`flowcat`](../../Flowmini/flowmini_v25_symboltable_projection/examples/apps/flowcat.flow).
