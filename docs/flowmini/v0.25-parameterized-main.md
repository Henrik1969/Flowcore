# Parameterized `main`

FlowMini accepts the canonical application entry point:

```flow
main(args : list<string>) {
}
```

The parameter is represented in the AST as an ordinary typed parameter and
projected into the `main` function scope in the SymbolTable. Its source
location and declared type spelling remain available to downstream analysers.

This establishes the language boundary for process arguments. It does not yet
promise general list operations or file-content streaming. The first executable
application profile, flowcat_argv_main, projects argument strings through the
authorized puts capability; file-content streaming remains a subsequent
standard-library boundary. The application specimen is
[`flowcat`](../../Flowmini/flowmini_v25_symboltable_projection/examples/apps/flowcat/README.md).
