# Flowanalyst algebraic graph projection

Flowanalyst's canonical semantic regions are exposed as an analysis graph and
as derived sparse matrix views.

```text
semantic regions
  → flowanalyst.analysis_graph v1
  → sparse algebraic views
```

The graph remains canonical. Matrix views are projections and may be rebuilt
from the graph at any time.

## Graph orientation

An edge means:

```text
prerequisite → dependent
```

For example:

```text
symbol:5 → target:cli
```

The same relation is represented in the `region_dependency` matrix as:

```text
A[prerequisite_index, dependent_index] = true
```

The first view uses COO storage and the Boolean semiring so it can be consumed
by a simple CPU implementation, a sparse linear-algebra provider, or a future
CUDA provider. Storage formats and providers may change; the graph relation and
orientation are the contract.

## Provider rules

- Matrix views are derived, never authoritative over the semantic graph.
- Node indices are valid only within one report.
- Providers must preserve graph provenance when returning facts or diagnostics.
- CPU and accelerator providers must produce equivalent canonical results.
- Providers may reject unsupported matrix versions or semirings explicitly.
- Consumers must not assume that `region_dependency` is the only future view.

The next algebraic providers can implement reachability, SCC condensation,
dependency layering, and fixpoint scheduling over this view.
